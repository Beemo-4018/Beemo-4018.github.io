🏃 재활운동 AI 동작평가 시스템

2026.03 ~ 2026.04 · MediaPipe · PyTorch · Transformer · OpenCV
Overview

물리치료사 5년 임상 경험을 바탕으로 재활 단계별 동작평가를 AI로 구현했습니다. MediaPipe 관절 추출 + PoseFormer 논문 구조의 Spatial-Temporal Transformer를 적용했으며, 모델 한계를 분석하고 규칙 기반으로 개선하는 과정을 거쳤습니다.

성과
97.3%Val Acc
4단계동작 인식
3종재활운동
재활 단계별 구성
  • 초기 재활 → SLR (Straight Leg Raise): 들어올린 각도 + 15초 타이머 + 골반 안정성 감지
  • 중기 재활 → Shoulder Ladder: 어깨 굴곡각도 + 체간 보상 감지 + 수평 외전 좌우 비대칭
  • 후기 재활 → Squat: 4단계 동작 인식 (standing/descending/bottom/ascending) + 횟수 카운팅
주요 역할
  • MediaPipe 33개 관절 중 스쿼트 핵심 관절만 선별 (팔 제외) → 물리치료사 임상 기준 직접 설계
  • PoseFormer 논문 구조 기반 Spatial + Temporal Transformer 직접 구현
  • 데이터 분포 분석으로 모델 한계 발견 → 각도 변화율 기반 규칙으로 개선
  • 정면/측면 자동 감지, 15초 타이머, GOAL REACHED 자동 캡쳐 구현
인사이트
  • Val Acc 97.3% 달성했지만 실시간에서 한계 발견 → 데이터 분포 분석으로 원인 파악
  • 스쿼트 핵심 관절만 선별하자 Val Acc 80.5% → 96.5% 향상 — 임상 지식이 성능 개선에 직접 기여
  • 단순한 규칙 기반이 복잡한 모델보다 실시간에서 더 나은 경우가 있음을 체득
기술 스택

🧠 DICOM & MRI 복원 AI 파이프라인

2026.03 · PyTorch · pydicom · h5py · UNet
Overview

실제 CT DICOM 데이터와 fastMRI 무릎 MRI 데이터로 SwiftMR과 동일한 구조의 k-space 언더샘플링 → UNet 복원 파이프라인을 end-to-end로 구현했습니다.

성과
+2.04 dBPSNR 향상
+0.119SSIM 향상
↓ 79%CT Loss 감소
주요 역할
  • DICOM 표준(HU 변환, Windowing) 학습 및 pydicom 기반 CT 전처리 파이프라인 설계
  • 189개 DICOM 슬라이스 → 3D 볼륨(189×512×512) 구성 및 PyTorch DataLoader 연결
  • fastMRI 무릎 MRI 데이터셋으로 k-space 언더샘플링(가속도 4배) → UNet 복원 구현
  • MSE+SSIM Combined Loss 적용으로 엣지 선명도 개선
